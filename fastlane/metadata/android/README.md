# Play listing metadata (fastlane supply layout)

- `en-US/` is the default listing; `fi-FI/` is the Finnish one.
- `video.txt` is intentionally empty in both locales. Once the promo video is recorded and uploaded
  to YouTube (see `fastlane/VIDEO.md`), put its plain URL on one line, for example
  `https://www.youtube.com/watch?v=XXXXXXXXXXX`. It must be public or unlisted, embeddable, without ads
  and without age restriction. The same URL can go in both locales.
- `changelogs/<versionCode>.txt` holds each version's notes (max 500 characters); Play shows the one
  matching the uploaded versionCode.
- `tenInchScreenshots/` are raw captures from a Galaxy Tab A9+ (System UI demo mode, release build,
  1920x1200 and 1200x1920, saved as RGB): landscape Sources, Channels and Keys, portrait Channels.
- The other images are generated by `fastlane/tools/render.py`; text limits are checked by
  `python -I fastlane/tools/check_text.py fastlane/metadata/android`.
